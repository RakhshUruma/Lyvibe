01レイアウト全体

3レイヤ構成。背景の Stage が全画面、その手前に半透明のフローティング UI が乗る。

┌───────────────────────────────────────────────────────────┐ │ │ │ │ │ STAGE (full-screen) │ │ │ │ ━━━━━━━━━━━━━━━━━ │ │ ＨＥＡＲＴＢＥＡＴ │ │ ━━━━━━━━━━━━━━━━━ │ │ │ │ │ │ ┌─────────────────┐ │ │ │ PANEL │ │ │ │ (bottom-right) │ │ │ └─────────────────┘ │ │ │ │ ┌─────────────────────────────────┐ │ │ │ ▶ ■ 1:23 / 3:42 [━━━━━━━] │ │ │ └─────────────────────────────────┘ │ │ TRANSPORT (bottom-center) │ └───────────────────────────────────────────────────────────┘
Stage = 背景描画 + 歌詞描画 Panel = 全コントロール Transport = 再生制御(再生中常駐)

UI は最小化可能。Panel を最小化 → タイトルバーだけ残る。Transport は常時表示。

02Stage

4段の z-stack で構成される全画面領域。LLM生成 CSS は #bgCssLayer に閉じ込められ、歌詞レイヤ(z=50)を侵さない。

2#bgCssLayerカスタム mood の CSS 背景(LLM が ::before/::after 込みで生成)。isolation: isolate で stacking context 隔離
50#lyricsLayer歌詞行(.line)の絶対配置領域。!important で z 固定
51#fxLayerゴーストエコー等の追加エフェクト
ＶＪ　ＬＹＲＩＣＳ

歌詞 1 行の構造

.line(position: absolute; left: x%; top: y%; transform: translate(-50%,-50%); rotate: tiltdeg)
  └─ .ch × N (1文字 1 span)
      ├─ inline animation: 「entry KF」 + 「motion KF」(CUSTOM mood時)
      └─ .shown class でアニメ起動 / opacity 1 化

各行はランダムで:

  • 位置 — center モード or scatter モード(3×3グリッド + 微オフセット)
  • サイズ — 文字数ベース ±25%
  • 傾き — mood の tilt 範囲内でランダム
  • entry / motion アニメ — mood 配列からランダム1個
  • glitch / ghost — 確率発動

05Lyric Editor

v1.1 で追加される目玉機能。停止 / 一時停止時、現在再生中だった行が編集カードに自動展開されインライン修正できる。

表示タイミング

  • ■ STOP 押下時 → 直前再生中だった行を表示
  • ⏸ PAUSE 押下時 → 現在行を表示
  • 再生中に E 押下 → 自動 pause + 現在行を表示
  • 副パネル(全行リスト)の行クリック → その行を表示 + 該当時刻シーク

フィールド

  • text — 1 行のテキスト
  • start — 秒(小数可)
  • end — 秒(小数可)

アクション

  • Apply — 配列に反映 + 自動ソート + 永続化
  • Prev / Next — 前/後の行に移動
  • Split — このシーク位置で行を 2 つに分割
  • Insert before / after — 空行追加
  • Delete — この行を削除

06Status / Source 表示

API キー UI を撤去した代わりに、現在使えるソースを縦並びで表示する。クリックで probe 再実行。

シンボル意味
✓利用可能(probe 成功 or キー設定済)
✗利用不可(認証エラー / 接続失敗)
?未確認(押下 or 初回呼出時に判定)

下部のメッセージ行(従来 #status)

状態例

07状態バリエーション

1. 初期(キー無し / 音声無し)

STATUS は ✗ 多め、CTA は無効化されない(MCP / relay でも動く可能性のため)。Generate 押下時に dispatcher が判定。

2. 再生中 / panel 最小化

#panel.minimized で body が display:none、bar(タイトル+トグル)のみ残る。Transport は別途常駐。

3. CUSTOM mood 適用中

panel header の .meta が custom 表示。#dynamic-mood-style に keyframe 群、#dynamic-bg-style に現在 variant。各行ごとに bgSwapRate で variant 切替。

4. Lyric Editor open

Panel と並列(右下、Panel の下)に Editor カード。Editor 中は再生停止。Apply で再生再開しない(意図的)。

5. Export 中

専用フルスクリーンオーバーレイ:

┌──────────────────────────────────────┐ │ │ │ ◐ RENDERING │ │ ━━━━━━━━━━━━━━━ 38% │ │ 1:24 / 3:42 · 720p30 │ │ │ │ [ CANCEL ] │ │ │ └──────────────────────────────────────┘

レンダ中の現フレームを背景に薄く表示、進捗バー + キャンセル。

6. エラー(全 LLM ソース失敗)

status は赤、Paste mood JSON が赤フレームで強調、preset セレクタも操作可能(逃げ道)。

08デザイントークン

UI chrome は mood 色から完全分離。これにより custom mood の色がどんなに暗くても UI は読める。

カラー

--ui-faintplaceholderrgba(232,237,245,0.18)
--ui-edge枠線・区切りrgba(255,255,255,0.08)
--ui-accentアクセント / ドット / focus / CTA グラデ起点#6fe9ff
--ui-warmサブアクセント / CTA グラデ終点 / エディタ枠#ff5fa0
--ui-bg / --ui-bg-2パネル背景(2階調)rgba(12,12,20,0.92) 系

動的(mood 由来)

これらは custom mood で書き換わるが UI には流入させない:

  • --bg / --accent / --hot / --cool — 文字エフェクト・背景演出
  • --rgb-split / --line-font / --line-weight / --line-color / --line-blur — 歌詞描画
  • --bass / --energy — 毎フレーム JS 更新、CSS から音反応
